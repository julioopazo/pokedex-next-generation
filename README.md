# Pokedex Next Generation

Sitio web estático creado para el desafío de Programación Front End.

## Descripción

Pokedex Next Generation consume datos desde PokéAPI y muestra una galería responsiva de Pokémon. Incluye búsqueda por nombre, carga por generación, botón para cargar más, modo claro/oscuro y sistema de favoritos usando localStorage.

## Tecnologías usadas

- HTML5 semántico
- CSS3 responsivo
- JavaScript
- Fetch API
- PokéAPI
- Git y GitHub Pages

## Funcionalidades

- Galería de tarjetas Pokémon.
- Consumo de API pública.
- Buscador por nombre.
- Selector de generación.
- Botón Cargar datos para cargar la generación seleccionada.
- Botón Cargar más para agregar más tarjetas.
- Botón Ver todos para mostrar completa la generación seleccionada.
- Modo claro/oscuro.
- Favoritos con localStorage.
- Colores por tipo Pokémon.
- Favicon personalizado.
- Manejo de errores con try/catch.
